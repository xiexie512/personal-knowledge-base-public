想按主题找，用右上角搜索。

## 和其他仓的分工

| 仓库 | 可见性 | 放什么 |
|---|---|---|
| **personal-knowledge-base-public**（本仓） | 公开 | 定稿成品 + 本站点 |
| `personal-knowledge-base` | 私有 | 工程源码、脚本、排障过程、草稿 |

## 入库标准

- 结论稳定、能独立读懂，才算定稿，才允许进这里；
- 含密钥、口令、内网地址、未验证猜测的内容一律留在私有仓；
- 新增文件要同步更新 `_sidebar.md`，否则站点里点不到。
